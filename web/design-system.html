Foundations

Color

Five chromatic ramps plus a 14-step neutral ramp. Each hue carries meaning — blue for active state, green for success, orange for attention, red for problems, purple for brand. The same palette drives both light and dark modes; only the mapping changes.

Alpha

Transparent overlays used to shade an element against whatever surface sits below it.

Foundations

Semantic tokens

Raw scale values are never used directly in components. Instead, intent-named tokens (text, border, background, feedback) point at scale steps and re-map per color mode. This is what makes dark mode a one-attribute switch.

Typography

GitLab Sans (an Inter derivative) for UI, GitLab Mono (a JetBrains Mono derivative) for code. A single dynamic scale from 12px meta text up to a 28px display size. Two weights carry the whole hierarchy: 400 for body, 600 for emphasis.

Foundations

Spacing

An 8px base system. Geometric progression through 16px, then n × 1.5 for larger steps. 2–4px lives inside a component, 8px separates related elements, 16px separates unrelated ones, 24–32px separates sections.

Foundations

Border & radius

Borders are 1px by default (2px for emphasis). Radius runs from a 1px hairline to a full pill, tied to the spacing scale. Nest concentrically: outer radius − padding = inner radius.

Elevation

Three shadow levels. Small defines an interactive surface at rest; medium lifts hover surfaces, dropdowns, and popovers; large carries modals and drawers that sit well above the page.

Motion

Animation is used sparingly and always respects prefers-reduced-motion. Three easing curves and four durations cover the system. Click a card to replay.

Dropdown, tooltip & modal

Layered surfaces. Dropdowns and popovers use the medium shadow; modals use the large shadow over a dimming overlay.

Components

Toasts / notifications

Brief, self-dismissing confirmations anchored bottom-right, with an optional single action. They slide in on an out-cubic curve and never block the interface.

Feedback

Loaders & spinners

Indeterminate waiting states. The spinner uses a linear rotation; the dots pulse in sequence for inline "thinking" moments.

Feedback

Skeletons

Placeholder geometry for content that hasn't loaded, using a 1s linear shimmer. Match the skeleton's shape to the real content to avoid layout shift.
